项目架构 (Project)
CodeAgent
se.codeagent.core
CodeAgent 是一个基于原生 Python 与 ReAct 架构构建的轻量自愈代码开发助手。全系统由客户端交互、验证通道、桌面宿主、操作契约、网络传输、代码执行器、工件存储、账号会话、多模型适配层及核心运行时构成。

通过「读取文件 -> 编写代码 -> 运行测试 -> 捕获报错 -> 自主反思修复」形成完整的软件工程自愈开发闭环。
